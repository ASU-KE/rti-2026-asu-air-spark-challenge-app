# Use human-accountable Human-Agent Pair Programming

The team will extend pair programming through Interactive Pairing and Delegated Pairing rather than treating agents as independent owners. Agents may perform autonomous or ticket-authorized work within approved boundaries, while a named human remains accountable and explicitly approves merges, deployments, risk acceptance, elevated credential use, destructive actions, and product-scope changes; this balances delivery speed with enterprise accountability.
