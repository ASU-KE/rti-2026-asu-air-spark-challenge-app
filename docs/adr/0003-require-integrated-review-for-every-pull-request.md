# Require integrated review for every pull request

Every pull request in both the Standard and Event-Critical lanes will use one `/code-review` entry point that integrates specification and standards checks, ET pull-request and security reviews, independent reviewers from different model families, cross-validation, and a synthesized merge recommendation. Applying the same assurance workflow to every pull request costs time and model usage, but avoids ambiguous routing, lane-specific quality, and unreviewed security assumptions during the aSDLC Pilot.
