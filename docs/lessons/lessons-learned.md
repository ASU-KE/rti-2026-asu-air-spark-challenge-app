# Lessons Learned





Notes:

We can execute multiple agent workflows in separate sessions, but it is critical to clone multiple copies of the application repo to prevent agent collision!

The speed of the available orchestrator-capable models prevented us from maintaining the needed velocity. Issues with session reliability or setup mistakes were costly and prevented the progress we needed.

I think AIR is a fantastic platform, and with sufficient time for execution and better fine-tuning of the OpenCode harness--not to mention better-optimized skills library--I can see this as viable platform for time-insensitive projects.
