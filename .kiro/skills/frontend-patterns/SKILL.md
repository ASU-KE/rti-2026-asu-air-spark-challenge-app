# Frontend Development Patterns

Reference for Next.js and cross-cutting UI work. Open the file for the concern in front of you:

- [Component & hook patterns](components.md) — composition, compound components, render props, and custom hooks (toggle, async query, debounce).
- [State management](state-management.md) — Context + reducer for shared app state, accessed through a provider-guarded hook.
- [Performance](performance.md) — memoization, code splitting and lazy loading, list virtualization.
- [Forms](forms.md) — controlled inputs with submit-time validation and per-field errors.
- [Interaction patterns](interaction-patterns.md) — error boundaries, Framer Motion animation, keyboard navigation, and focus management.
